# 家庭药箱管家

一个帮助家庭管理药品、追踪有效期、防止药品浪费的移动应用。

## 问题痛点

很多人买了感冒药、消炎药后就扔在抽屉里，等到下次生病想吃时，发现已经过期了，或者说明书丢了不知道用量。市面上的健康App太重（挂号、问诊），没有专门管"家里存药"的工具。

## 核心功能

### 1. 扫码录入
- 扫描药盒条形码
- 自动调用公开API获取药品名称、功效、用法
- AI编程可以帮助编写API对接代码

### 2. 过期提醒
- 录入保质期
- 过期前1个月、1周自动推送提醒
- 直观的过期状态显示

### 3. 用药记录
- 简单的点击记录"谁、什么时候、吃了什么"
- 防止重复吃药
- 历史用药记录查询

### 4. 家庭共享
- 数据存在云端（简单的Firebase/Supabase后端）
- 家里老人吃没吃药，儿女能看到
- 家庭成员之间实时同步

## 技术实现

### 前端技术
- React Native：跨平台开发（iOS + Android）
- Native Camera API：条形码扫描
- 本地通知API：过期提醒

### 后端服务
- Firebase/Supabase：用户认证 + 数据存储
- 无需复杂后端逻辑
- 简单的CRUD操作即可

### API集成
- 药品数据库公开API
- 条形码识别服务
- 推送通知服务

## 为什么能爆？

1. **极其刚需**：每个家庭都有药品管理的需求
2. **受众全**：老中青全年龄段的家庭用户
3. **工具属性强**：实用性强，不是可有可无
4. **市场空白**：目前没有绝对的头部产品
5. **传播性强**：用户会主动推荐给家人使用
6. **技术门槛适中**：适合单人+AI辅助开发

## 竞争优势

- **专注性**：只做家庭药箱管理，不做其他健康功能
- **简单性**：操作简单，老人也能用
- **实用性**：解决真实痛点，不是伪需求
- **家庭性**：强调家庭共享，增加粘性

## 商业模式

- **免费版**：基础功能免费，本地存储
- **高级版**：云端同步、多人协作、高级提醒
- **企业版**：医院、药店、养老院等机构使用

## 开发建议

1. **MVP先行**：先做最小可用版本，验证需求
2. **用户反馈**：快速迭代，根据用户反馈改进
3. **AI辅助**：利用AI编程工具提高开发效率
4. **模块化设计**：便于后期扩展和维护
