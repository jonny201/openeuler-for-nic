关于我

大家好，我是 jonny201，一名专注于 Linux 内核与网络设备驱动开发的工程师。 我长期参与 openEuler 社区的建设，致力于为国产操作系统生态贡献高质量的 NIC（网络接口卡）驱动程序。

在内核驱动开发领域，我拥有丰富的经验，包括网卡固件适配、性能调优、SR-IOV 虚拟化以及 RDMA 高性能网络等方向。我相信开源协作的力量，并积极回馈社区。
